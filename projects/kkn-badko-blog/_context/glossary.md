# Glossary — kkn-badko-blog

| Term | Definition |
|------|------------|
| Blogger API (v3) | Google REST API used to read blog posts, pages, labels, and comments that back this site. |
| Next.js | React framework used for the frontend and server-side API/render layer. |
| App Router | Next.js routing model used for pages and server components. |
| ISR | Incremental Static Regeneration — serves static pages and revalidates them from the source on an interval. |
| SSG | Static Site Generation — pages built at build time. |
| SSR | Server-Side Rendering — pages rendered per request on the server. |
| Service layer | Server-side module that mediates all Blogger API calls and hides credentials. |
| Label | Blogger's term for a post category/tag; used for filtering. |
| SEO | Search Engine Optimization. |
| Open Graph | Metadata standard for rich link previews on social platforms. |
| JSON-LD | Structured-data format; `BlogPosting` schema used for posts. |
| Sitemap | `sitemap.xml` listing site URLs for crawlers. |
| Lighthouse | Google tool auditing performance, SEO, accessibility, best practices. |
| WCAG | Web Content Accessibility Guidelines. |
| NFR | Non-Functional Requirement. |
| CI/CD | Continuous Integration / Continuous Deployment. |
| ISR revalidation interval | Time after which a cached page is refreshed from Blogger. |
| IEEE 830 | Standard for Software Requirements Specifications. |
| IEEE 29148 | Requirements engineering standard (supersedes/extends IEEE 830). |
| ISO/IEC 25010 | Software product quality model. |
| PSR / CSR / FSAR | Royce's formal customer review gates: Preliminary, Critical, and Final Software Acceptance Reviews. |
| MVP | Minimum Viable Product. |
| Core Web Vitals | Google's set of user-experience performance metrics (LCP, CLS, INP) underpinning the Lighthouse performance score. |
| LCP | Largest Contentful Paint — time to render the largest visible element; "good" ≤ 2.5 s. |
| CLS | Cumulative Layout Shift — visual stability metric; "good" ≤ 0.1. |
| INP | Interaction to Next Paint — responsiveness metric; "good" ≤ 200 ms. |
| DTO | Data Transfer Object — a typed in-memory record projected from an API response (not persisted). |
| RUSP | Ready-to-Use Software Product (ISO/IEC 25051). |
| RTM | Requirements Traceability Matrix. |
| GWT | Given-When-Then — acceptance-criteria format. |
| MTBF | Mean Time Between Failures. |
| RBAC | Role-Based Access Control. |
| DPIA | Data Protection Impact Assessment. |
